# DoctorZet DZUSD Polygon Deployer

Aplicación web para desplegar DoctorZet USD Coin en Polygon PoS desde MetaMask.

- Nombre: DoctorZet USD Coin
- Símbolo: DZUSD
- Decimales: 6
- Red: Polygon PoS Mainnet
- Chain ID: 137
- USDC nativo: 0x3c499c542cEF5E3811e1192ce70d8cC03d5c3359
- No existe mint administrativo.
- DZUSD se emite únicamente contra USDC recibido por el contrato.
- La redención quema DZUSD y devuelve USDC 1:1.
